# Healthcare Analytics Dashboard using Excel

## Project Overview
This project is an interactive Healthcare Analytics Dashboard developed using Microsoft Excel. The project focuses on data cleaning, transformation, analysis, and dashboard creation to generate healthcare-related insights from multiple datasets.

The dashboard helps analyze patient health conditions, healthcare charges, smoking habits, BMI categories, diabetes status, surgeries, and transplant history through interactive visualizations and KPI metrics.

---

## Objectives
- Clean and preprocess healthcare datasets
- Handle missing and inconsistent data
- Perform data transformation and feature engineering
- Analyze healthcare charges and patient conditions
- Build interactive Excel dashboards using Pivot Tables and slicers
- Generate meaningful healthcare insights using visualizations
